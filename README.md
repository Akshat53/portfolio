# Akshat Kumar Singh — Portfolio

Professional portfolio built with Next.js, React, and Tailwind CSS.

**Live:** https://akshat-portfolio.vercel.app

## Features

- Next.js 14 with React 18
- TypeScript for type safety
- Tailwind CSS for styling
- Responsive design
- Optimized for performance
- SEO ready

## Development

```bash
npm install
npm run dev
# Open http://localhost:3000
```

## Build

```bash
npm run build
npm start
```

## Deployment

Automatically deployed on Vercel via GitHub integration.
